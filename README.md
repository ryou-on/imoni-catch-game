# 芋煮キャッチ！

落ちてくる芋煮の具材を鍋でキャッチする、ブラウザで遊べるミニゲームです。

**▶ 遊ぶ: https://ryou-on.github.io/imoni-catch-game/**

## 遊び方
- 鍋を左右に動かして（マウス／タッチ／矢印キー）、落ちてくる具材をキャッチ
- 具材ごとに得点と「旨味・コク・香り・甘み・とろみ」のパラメータが付きます
- 石と唐辛子はハズレ。お酒を取ると一時的に得点2倍
- 突風・具材ラッシュ・大鍋などのランダムイベントあり
- 終了時に具材の種類数とパラメータで「仕上がりボーナス」と芋煮ランクが付きます
